# qq-movie-search

给官方 QQ 机器人用的 `/电影` 搜片 skill：调用第三方公开接口（清和 API）搜片，用户在群里或私聊里回序号逐级选片、选线路、选集，机器人发出可点击的播放链接（群聊 Markdown 链接、私聊 Ark 大图卡），并在每一步作答后自动撤回上一条提示，让聊天框里只留最终结果。实现是单文件 `movie.mjs`（零第三方依赖），宿主只需提供发送与撤回两个平台能力；接入前先跑 `node smoke-test.mjs` 自检，再照 `node example-host.mjs` 的干跑示例仿写宿主接线，完整文档见 [SKILL.md](./SKILL.md)。

## 🤖 安装提示词（复制整段，发给你的 AI 助手）

把下面这一整段原样发给你的 AI 助手（比如 Muse），它就会照着本仓库的 SKILL.md 带你把功能装好：

```text
我想给我的官方 QQ 机器人装一个「/电影」搜片功能，仓库是 https://github.com/Mahiru0311/qq-movie-skill ，请你替我装好：

1. 先完整读仓库的 SKILL.md 和 DISCLAIMER.md，再动手，别跳步；
2. 把仓库文件取到本地，先跑 node smoke-test.mjs 自检（全绿才继续），再跑 node example-host.mjs 看干跑示例；
3. 按 SKILL.md 的「快速接入」把 movie.mjs 接进我的机器人宿主：宿主需要提供 sendText / sendMarkdown / recallMessage 三个方法，选片流程（选片→选线路→选集→出链接）和每步的答后撤回都照文档实现，不要自创流程；
4. 需要我提供的只有：QQ Bot 的 AppID 和 AppSecret、聊天大模型的接口地址和密钥。到这一步你开口要，给我安全的录入方式，不要让我把密钥明文贴在聊天里；
5. 装完做验收：自测全过，并且我真机发一条「/电影 蜘蛛侠」，能一路选到出播放链接、中间的提示消息都被撤回，才算装完；
6. 全程用大白话向我汇报，每完成一步说一次结果；文档里写过的实测结论（如群聊要用 Markdown 链接、Ark 大图卡只在私聊用）照着执行，不要自作主张换方案。
```
